# Current interface

The latest direction is minimal: study title and Upload action, transcript library and source reader. Promotional copy, privacy/status footers, duplicate counts, country-summary markers, colored avatars and sample-loading controls have been removed.

Typography: locally bundled Roboto. Palette: white surfaces, neutral grey text/borders, blue actions and selection. Mobile selection opens a focused reader with Back navigation. No new product features were added.

Verified: frontend production build, 16 backend tests, removed-copy DOM check, search with expert-only filtering, desktop 1440px, phone 390px, and upload dialog at 320px without horizontal overflow. Existing screenshots in docs/design/redesign-desktop.png and redesign-mobile.png reflect this version.

This remains Part 1 of the application. The visual cleanup does not claim completion of the later AI features or multi-user hosting.
