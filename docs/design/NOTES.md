# Visual direction and fidelity

Design brief: a native, minimal transcript workspace inspired by Google's restrained productivity interfaces. White background, dark neutral text, Google-blue actions, subtle grey borders, system sans-serif typography, and a split library/reader layout. No decorative dashboards, charts, gradients, oversized cards, or unimplemented AI navigation.

`concept.png` is the generated visual reference. `desktop.png` and `mobile.png` show the implemented product and were visually inspected.

| Reference point | Implemented result |
|---|---|
| White, blue and cool-grey palette | CSS tokens, restrained selection and action colors |
| Top Clearcall mark and help | Native four-square mark, working help dialog |
| Library at left, reader at right | 310px desktop library; mobile back navigation |
| Expert initials and readable metadata | Native text and small initials avatars |
| Source timestamps in a left gutter | Source-derived timestamp buttons and jump control |
| Subtle border and corner treatment | 1px grey lines, mostly 6–10px radii, no card shadows |
| Upload and sample actions | Connected to actual persistent backend |

Intentional changes: lighter typography and less decoration following the user's latest instruction; Anna Keller's role is the actual “Former Hospital Procurement Director”; passage count and jump control have their own compact row; smaller screens use a library-to-reader flow. No image is used as the app UI.
